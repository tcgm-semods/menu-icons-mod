# Menu Icons

Replaces the whole bottom-right HUD row (Menu / Minimap / Squad / Galaxy,
plus the Menu button's dropup: Stats / Friends / Missions / Coalition /
Attendance / Market) with a single row of nine icon buttons. No dropup is
drawn at all -- every action is a direct icon button, with a tooltip on
hover and a small red dot for items with pending notifications.

Icons are Feather Icons (MIT licensed), pre-rendered to PNG at mod-build
time and tinted to match the HUD's existing accent color.
