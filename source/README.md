# Menu Icons

Replaces the bottom-right HUD row (Menu, Minimap, Squad, Galaxy plus the Menu
button's dropup) with a RuneScape-style icon bar. Universe Map, Squad, Minimap
and Options are direct buttons; three category buttons drop up into a vertical
column of more icons:

- **Character**: Stats, Missions, Run Summary, Mechlings
- **Social**: Friends, Coalition, Mail
- **Economy**: Global Market, Attendance Rewards, Shop (while the server enables it)

Tooltip on hover, red dot for pending notifications (a category shows the dot
when anything inside it needs attention). Click a category again, click
elsewhere or press Esc to close its strip. Right-click the Universe Map button
to copy the current system name.

Icons are Feather Icons (MIT), pre-rendered to PNG at build time and tinted to
match the HUD's accent color; the Mechlings robot is drawn in the same style.
